# Celemo - Frontend course

Repo for our Celemo project. 
Here we build our webpage with React + Vite and connect to our Spring Boot backend.

1. Clone project
2. In terminal write: npm i
3. create a new file in source folder, named ".env"
4. in .env file write "VITE_API_URL=http://localhost:8080/api"
5. Run!
